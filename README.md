# one-page · 一页简历工作台

一个开源、本地优先的中文简历编辑器。使用 React、TypeScript、Vite，提供结构化编辑、实时 A4 预览、自适应间距和自定义主题。无需账号或后端。

## 启动

需要 Node.js 20.19+ 或 22 LTS。

```sh
git clone https://github.com/Amane-fan/one-page.git
cd one-page
npm ci
npm run dev
```

Windows 可双击 `start.cmd`，首次安装依赖后自动打开浏览器。默认地址为 `http://127.0.0.1:5173/`。首次安装需要网络，依赖就绪后可离线运行。

## 功能

- 个人信息、专业技能、实习、项目、荣誉等模块，支持增删、排序和隐藏。
- 左侧编辑、右侧实时预览；手机可切换编辑与预览。
- 有边界的 A4 自动排版：先调整间距，再缩小字号，最低 9pt；仍超出时提示精简，不裁切内容。
- 商务蓝、简洁黑白、低饱和绿主题，可修改颜色、黑体/宋体、字号和照片显示。
- 本地自动保存、最近 40 次修改撤销/重做、JSON 导入导出。
- 学校信息、技能、相关技术、项目描述和主要工作支持局部加粗：选中文字后点击“加粗”或按 Ctrl+B（macOS 为 ⌘B），再次操作可取消。编辑框以 `**文字**` 保存格式，预览与 PDF 显示实际粗体；JSON 和本地草稿保留标记，兼容原有纯文本备份。姓名和经历标题本身已加粗，联系方式保持纯文本。
- **直接生成 PDF**：保留可选择的中文文字、照片和链接，不调用打印窗口。

## PDF 保存到指定位置

在桌面 Chrome / Edge 中点击“导出 PDF”，选择文件夹与文件名，生成后写入所选文件。取消对话框不会修改任何文件；写入失败会提示，可重试。

文件选择 API 需要安全上下文（本机 localhost/127.0.0.1 或 HTTPS）。不支持该 API 的浏览器使用普通文件下载：可在浏览器下载设置中开启“每次询问保存位置”，或改用桌面 Chrome / Edge。应用不能绕过浏览器限制强制打开系统对话框。

PDF 在浏览器内生成，字体随项目提供，不访问远程字体或文档转换服务。首次使用字体可能需要短暂加载。为避免不同阅读器缺字，当前导出完整内嵌中文字体，文件通常约 13–18 MB（照片另计）。预览使用同一套字体与布局，导出不重新计算另一套版面。

## 隐私与本地数据

仓库仅提供**匿名初始化模板**；姓名、电话、学校、经历、照片等需要由使用者填写。

- 编辑内容保存在当前浏览器、当前站点地址的 localStorage 中，不进入源代码或 Git，也不发送到服务器。
- 使用 **导出 JSON** 备份内容、照片与主题，使用 **导入**恢复。建议将个人备份放在仓库目录之外。
- 换浏览器、更换端口或清理浏览器数据后，原草稿不会自动出现。JSON 导入保留版本、类型、大小及照片格式校验。
- 开源代码中的 `src/data/resume.json` 始终保持匿名。**不要将自己的导出文件替换此文件后提交。**
- 个人 PDF、照片、导出备份、本地日志、测试产物、环境文件已加入忽略规则。
- 浏览器本地存储并非加密保险箱；同一浏览器配置的其他使用者可访问草稿。

## A4 自适应原理

固定 210 × 297 mm，页边距上下 9 mm、左右 10 mm。按浏览器真实内容高度，二分寻找允许范围内的最大间距，必要时缩小字号。预留 2px 换算余量。内容少时保留自然留白，不夸张拉伸；内容过长时显示超出毫米数与受影响模块，并阻止导出。

屏幕预览只缩放整张纸，手机不会改变纸张内部换行。字体、主题、内容变化均重新测量。

## 开发

```sh
npm run build       # TypeScript 检查与生产构建
npm test            # 浏览器回归，需要已安装 Chrome
npm run privacy     # 提交前检查匿名模板与追踪文件
npm run format      # 整理代码格式
npm run preview     # 本地查看构建结果
```

- `src/data/resume.json`：匿名模板。
- `src/model.ts`：数据模型与导入校验。
- `src/Resume.tsx`：纸张渲染。
- `src/fit.ts`：A4 自适应测量。
- `src/pdf.ts`：本地矢量 PDF 生成（按需加载）。
- `src/save.ts`：文件位置选择、写入与兼容下载。
- `src/App.tsx`：编辑、主题、草稿与备份交互。
- `scripts/privacy-check.mjs`：公开仓库隐私检查。

静态构建在 `dist/`，不需要部署后端。当前字体路径以站点根目录为基准，如部署到子路径，需同步调整 Vite base 与 CSS 字体路径。
