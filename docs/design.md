# 设计决策

界面采用 Framed sheet（seed 224323379）的浅色纸张工作台：左侧结构化编辑，右侧真实 A4 纸张预览。手机可切换编辑与预览。内容默认使用明确的填写提示，不预置真实简历。

A4 测量有明确间距和字号边界；过短自然留白，过长明确提示。预览与 PDF 使用随项目打包的开源中文字体，PDF 根据 DOM 已排版的文本行、标题背景和照片位置绘制矢量文字及链接注释。

选择保存位置必须发生在用户点击时，耗时的字体加载与 PDF 生成随后执行。生成文件只写入用户选择的句柄，不经过后台服务器。取消选择不生成文件；写入异常中止文件流。非兼容浏览器以下载方式回退并提示。

结构化数据与代码分离。默认模板匿名，个人草稿不进入 Git，JSON 是跨浏览器迁移和备份的边界。
