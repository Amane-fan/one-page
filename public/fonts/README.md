# 中文字体

来源：Google Fonts 的 Noto Sans SC 与 Noto Serif SC，可变字体使用 fontTools 转为 wght=400/700 的静态 TrueType 实例，未修改字形设计。许可：SIL Open Font License 1.1，见同目录 OFL 文件。

- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notoserifsc

字体随应用本地分发，预览与 PDF 共用。为保证不同 PDF 阅读器中的中文兼容性，PDF 嵌入完整的常规和粗体字体。不要用未获再分发许可的系统字体替换这些文件。
